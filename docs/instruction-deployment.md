# Инструкция по развёртыванию стенда

## Включение базовой сети

Подключить к питанию сетевой концентратор NETCRAZE, дождаться его инициализации до появления в эфире WiFi SSID:IS-1

Сетевой концентратор автоматически осуществляет подключение к WiFi-сети интернет-провайдера с SSID:D-WIFI-NEO-510-5
Доступ в интернет для работы стенда НЕОБЯЗАТЕЛЕН!
В случае отсутствия сети интернет-провайдера работа стенда будет возможна без каких-либо ограничений.

Учётные данные для идентификации в сети IS-1 написаны на корпусе сетевого концентратора

## Включение терминала управления стенддом

Включить ноутбук и выполнить вход в систему
user: `INTSIS`
pass: `intsis`
pin : `1313`

Убедиться что ноутбук подключён к wifi:IS-1

## Подключение вычислительных модулей LTE-сети стенда

Вычислительные модули LTE-сети стенда выполнены на основе одноплатных микрокопьютеров Raspbery Pi5.

Включение и отключение модулей стенда возможно в любой последовательности. 

На всех модулях нанесены учётные данные для осуществления удалённого подключения к ним в формате

`ssh имя_пользователя@название_компьютера_в_сети`
pass: `пароль_для_подключения` 

Для базовых станций указаны значения частот каналов `up_link/down_link` в МГц

### Включение модуля ядра сети

Модуль ядра реализован в устройстве с соответствующей маркировкой на корпусе "Ядро сети".

Необходимо подключить модуль к блоку питания проводом USB-C. Блок питания должен обладать мощнстьб не ниже 24 Вт.

После подачи питания модуль ядра сети включается автоматически. На передней части модуля статусный светодиод (вмонтированный в кнопку управления) должен изменить свой цвет на зелёный.

### Включение модуля базовой станции

Перед подключением к питанию модуля базовой станции необходимо подготовить к работе SDR-приёмник.

#### Водготовка SDR-приёмника

В качестве SDR-приёмника в составе БС может быть использован USRP b210, либо PLUTO SDR

- Необходимо подключить две антенны к каналам TX/RX-A и RX-A (приёмный и передающий канал A);
- Необходимо подключить с помощью кабеля данных (USB-C/USB-B <--> USB-A) SDR-приёмник и Raspberry PI5.

На Raspberry PI5 использовать чёрный порт USB2.0 (обладает большей стабильностью по питанию)

#### Включени ебазовой станции

После коммутации SDR-приёмника с Raspberry PI5 можно подать питание на модуль базовой станции. Для питания базовой станции требуется блоки питания с мощностью не меьше 45 Вт.

После подключения питания к модулю для его включения нужно однократко кратковременно нажать на кнопку на задней части корпуса. После этого на передней части корпуса внизу статусный светодиод должен загореться зелёным цветом.

## Проверка статуса работы сети стенда

На ноутбуке "терминала управления" открыть командную строку

### Проверка доступности узлов

1. Проверить доступность в сети базовой станции. Для этого выполнить пинг до компьютера в локальной сети с именем `base5`

```shell
ping base5
```

В результате выполнения команды `ping` должны быть отображены результаты ответов с задержками времени порядка 2-10 мс. Потерь пакетов быть не должно. Адрес целевого компьютера в сети должен быть определён как `192.168.1.25`.

2. Првоерить доступность в сети ядра сети. Для этого выполнить пинг до компьютера в локальной сети с именем `pi5-2`

```shell
ping pi5-2
```

В результате выполнения команды `ping` должны быть отображены результаты ответов с задержкой порядка 2-10 мс.
Потерь пакетов быть не должно. Адрес целевого компюьтера в сети должен быть определён как `192.168.1.20`
