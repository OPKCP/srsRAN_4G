# rr.conf — Конфигурация радиоресурсов (Radio Resources)

Файл конфигурации радиоресурсов для eNB в проекте srsRAN 4G. Содержит параметры физического уровня (PHY), MAC, управления мощностью, конфигурацию ячеек, отчётов об измерениях и хэндовера.

## Структура файла

Конфигурация `rr.conf` имеет собственный формат (не INI-style, а C-подобный с использованием `{}`, `=` и `;`). Файл состоит из нескольких корневых блоков:

```
mac_cnfg = { ... };           // MAC-конфигурация
phy_cnfg = { ... };           // PHY-конфигурация
cell_list = ( ... );          // Список LTE ячеек
nr_cell_list = ( ... );       // Список NR ячеек
```

## Раздел mac_cnfg — MAC-конфигурация

### phr_cnfg — Конфигурация PHR (Power Headroom Report)

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `dl_pathloss_change` | Порог изменения DL pathloss для триггера PHR. | `dB1`, `dB3`, `dB6`, `INFINITY` | `dB3` |
| `periodic_phr_timer` | Периодический таймер PHR (в подкадрах, 1 подкадр = 1 мс). | Целое число ≥ 0 | `50` |
| `prohibit_phr_timer` | Таймер запрета PHR (в подкадрах). | Целое число ≥ 0 | `0` |

### ulsch_cnfg — Конфигурация UL-SCH

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `max_harq_tx` | Максимальное количество HARQ-передач (UL). | `1` – `28` | `4` |
| `periodic_bsr_timer` | Периодический таймер BSR (Buffer Status Report) в мс. | Целое число ≥ 0 | `20` |
| `retx_bsr_timer` | Таймер повторной передачи BSR (мс). | Целое число ≥ 0 | `320` |

### time_alignment_timer

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `time_alignment_timer` | Таймер выравнивания времени (мс). `-1` — бесконечность. | `-1` (бесконечность) или положительное целое | `-1` |

## Раздел phy_cnfg — PHY-конфигурация

### phich_cnfg — PHICH (Physical Hybrid-ARQ Indicator Channel)

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `duration` | Длительность PHICH. | `Normal`, `Extended` | `Normal` |
| `resources` | Ресурсы PHICH (доля от общего числа ресурсных элементов). | `"1/6"`, `"1/2"`, `"1"`, `"2"` | `"1/6"` |

### pusch_cnfg_ded — PUSCH dedicated (выделенные параметры PUSCH)

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `beta_offset_ack_idx` | Индекс beta-смещения для ACK. | `0` – `15` | `6` |
| `beta_offset_ri_idx` | Индекс beta-смещения для RI (Rank Indicator). | `0` – `15` | `6` |
| `beta_offset_cqi_idx` | Индекс beta-смещения для CQI. | `0` – `15` | `6` |

### sched_request_cnfg — Scheduling Request (SR) конфигурация

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `dsr_trans_max` | Максимальное количество SR-передач. | `4`, `8`, `16`, `32`, `64` | `64` |
| `period` | Период SR (мс). | `1`, `2`, `5`, `10`, `20`, `40`, `80` | `20` |
| `subframe` | Вектор индексов подкадров для SR (опционально). | Список целых чисел | — |
| `nof_prb` | Количество PRB на каждом краю для SR. Общее количество PRB = 2 × nof_prb. | Целое число ≥ 1 | `1` |

> **Структура PUCCH-SR:** Ресурсы SR планируются сначала в частотно-временной области, затем мультиплексируются в одном ресурсе.

### cqi_report_cnfg — Конфигурация CQI-отчётов

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `mode` | Режим CQI-отчётов. | `periodic`, `aperiodic` | `periodic` |
| `simultaneousAckCQI` | Одновременная передача ACK и CQI. | `true` / `false` | `true` |
| `period` | Период CQI-отчётов (мс). | Целое число ≥ 2 | `40` |
| `subframe` | Вектор индексов подкадров для CQI ресурсов (опционально). | Список целых чисел | — |
| `m_ri` | Период RI в единицах периода CQI. | Целое число ≥ 1 | `8` |
| `subband_k` | Если > 0 — включает sub-band CQI (K — параметр из 3GPP 36.213 7.2.2). | `0` (wideband) или целое > 0 | — |

## Раздел cell_list — Список ячеек

Список ячеек (одна или несколько) определяется как массив структур:

```
cell_list = ( { cell1 }, { cell2 }, ... );
```

### Параметры ячейки

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `rf_port` | Порт RF для данной ячейки. | Целое число ≥ 0 | `0` |
| `cell_id` | 28-битный идентификатор ячейки (E-UTRAN Cell Identifier). | `0x0000000` – `0xFFFFFFF` | `0x01` |
| `tac` | Tracking Area Code (16 бит). | `0x0000` – `0xFFFF` | `0x0007` |
| `pci` | Physical Cell Identifier. | `0` – `503` | `1` |
| `root_seq_idx` | Индекс корневой последовательности PRACH. | `0` – `837` | `204` |
| `dl_earfcn` | Номер EARFCN для DL. | `0` – `65535` | `1300` |
| `ul_earfcn` | Номер EARFCN для UL (если отличается от DL). | `0` – `65535` | — |
| `ho_active` | Включить поддержку хэндовера. | `true` / `false` | `false` |
| `meas_gap_period` | Период измерительных гэпов (мс). `0` — отключены. | `0` (откл.), `40`, `80` | `0` |
| `meas_gap_offset_subframe` | Смещение подкадров для измерительных гэпов. | Список целых | — |
| `target_pusch_sinr` | Целевой SINR для PUSCH (дБ). `-1` — авто. | Любое число | `-1` |
| `target_pucch_sinr` | Целевой SINR для PUCCH (дБ). `-1` — авто. | Любое число | `-1` |
| `enable_phr_handling` | Включить обработку PHR (Power Headroom Report). | `true` / `false` | `false` |
| `min_phr_thres` | Минимальный порог PHR. | Целое число | `0` |
| `allowed_meas_bw` | Максимальная полоса для измерений (в PRB). | `6`, `15`, `25`, `50`, `75`, `100` | `6` |
| `t304` | Таймер T304 для хэндовера (мс). | `50`, `100`, `150`, `200`, `500`, `1000`, `2000` | `2000` |
| `tx_gain` | Дополнительный коэффициент усиления Tx для ячейки (дБ). | Любое число (дБ) | — |

### scell_list — Вторичные ячейки (CA, Carrier Aggregation)

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `cell_id` | ID вторичной ячейки. | `0x00` – `0xFF` | — |
| `cross_carrier_scheduling` | Использовать кросс-несущее планирование. | `true` / `false` | `false` |
| `scheduling_cell_id` | ID планирующей ячейки. | Целое | — |
| `ul_allowed` | Разрешить UL на данной ячейке. | `true` / `false` | `true` |

### meas_cell_list — Соседние ячейки (для хэндовера)

Список ячеек, доступных для хэндовера:

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| `eci` | E-UTRAN Cell Identifier (28 бит). | `0x0000000` – `0xFFFFFFF` |
| `dl_earfcn` | EARFCN соседней ячейки. | `0` – `65535` |
| `pci` | Physical Cell Identifier соседней ячейки. | `0` – `503` |
| `direct_forward_path_available` | Доступен прямой путь для forwarding-пакетов. | `true` / `false` |
| `allowed_meas_bw` | Макс. полоса измерений для соседней ячейки (PRB). | `6`, `15`, `25`, `50`, `75`, `100` |
| `cell_individual_offset` | Индивидуальное смещение для cell-specific offset (дБ). | `-24` – `24` |

### meas_report_desc — Конфигурация измерительных отчётов

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `eventA` | Тип события A (номер). | `1` – `5` (A1–A5) | `3` |
| `a3_offset` | Смещение для события A3 (дБ). | `-30` – `30` дБ | `6` |
| `hysteresis` | Гистерезис (дБ). | `0` – `30` дБ | `0` |
| `time_to_trigger` | Время до триггера (мс). | `0`, `40`, `64`, `80`, `100`, `128`, `160`, `256`, `320`, `480`, `512`, `640`, `1024`, `1280`, `2560`, `5120` | `480` |
| `trigger_quant` | Измеряемая величина для триггера. | `RSRP`, `RSRQ` | `RSRP` |
| `max_report_cells` | Максимальное количество отчётов о сотах. | Целое ≥ 1 | `1` |
| `report_interv` | Интервал отчёта (мс). | Целое ≥ 0 | `120` |
| `report_amount` | Количество отчётов. | Целое ≥ 0 | `1` |

#### Пояснение событий (eventA)

| Значение | Событие | Описание |
|----------|---------|----------|
| 1 | A1 | Сигнал serving cell становится лучше порога |
| 2 | A2 | Сигнал serving cell становится хуже порога |
| 3 | A3 | Соседняя ячейка становится лучше serving cell на величину offset |
| 4 | A4 | Соседняя ячейка становится лучше порога |
| 5 | A5 | Serving cell хуже порога 1 И соседняя ячейка лучше порога 2 |

### meas_quant_desc — Конфигурация измерительных величин

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `rsrq_config` | Коэффициент фильтра RSRQ. | `0` – `20` | `4` |
| `rsrp_config` | Коэффициент фильтра RSRP. | `0` – `20` | `4` |

> **Коэффициент фильтра:** Определяет "вес" прошлых измерений в экспоненциально взвешенном скользящем среднем (EWMA) согласно 3GPP TS 36.331. Формула: $F_n = (1 - 0.5^{(k/4)}) \cdot M_n + 0.5^{(k/4)} \cdot F_{n-1}$, где $k$ — коэффициент фильтра.

## Примечания

1. **Формула EARFCN → частота:** $F = F_{low} + 0.1 \times (N - N_{offset})$ по 3GPP TS 36.101.
2. **PHICH `resources`:** Задаётся в виде дроби, например `"1/6"`. Значение может быть `"1/6"`, `"1/2"`, `"1"`, `"2"` и определяет количество ресурсных групп PHICH.
3. **PUCCH-SR:** Ресурсы PUCCH для Scheduling Request планируются в частотно-временной области и мультиплексируются.
4. **CQI subband_k:** Если `subband_k` не задан или равен 0, используется wideband CQI. Иначе включается sub-band CQI с параметром K по 3GPP 36.213.
5. **Измерения для хэндовера:** Измерительные отчёты настраиваются как комбинация meas_cell_list и meas_report_desc. Все отчёты комбинируются со всеми объектами измерений.
6. **T304:** Таймер хэндовера — если хэндовер не завершён за указанное время, UE возвращается к исходной ячейке.
