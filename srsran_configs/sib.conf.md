# sib.conf — Конфигурация системных информационных блоков (SIB)

Файл конфигурации системных информационных блоков (SIB) для eNB в проекте srsRAN 4G. Содержит SIB1, SIB2, SIB3 и SIB5 согласно спецификациям 3GPP TS 36.331.

## Содержание

- [SIB1 — System Information Block Type 1](#sib1--system-information-block-type-1)
- [SIB2 — System Information Block Type 2](#sib2--system-information-block-type-2)
- [SIB3 — System Information Block Type 3](#sib3--system-information-block-type-3)
- [SIB5 — System Information Block Type 5](#sib5--system-information-block-type-5)

## Примечания

1. **Расчёт мощности передачи PUSCH/PUCCH** согласно 3GPP TS 36.213:

   $P_{PUSCH} = \min\{P_{MAX}, 10 \log_{10}(M) + P_0 + \alpha \cdot PL + \Delta_{TF} + f\}$

   где $M$ — количество RB, $PL$ — pathloss, $\alpha$ — коэффициент компенсации, $f$ — TPC-команда.

2. **Расчёт RSRP из q_rx_lev_min:**

   $Q_{rxlevmin} [дБм] = q\_rx\_lev\_min \times 2$

   Например, `q_rx_lev_min = -65` соответствует $Q_{rxlevmin} = -130$ дБм.

3. **SIB5** должен быть добавлен в `si_mapping_info` в SIB1, чтобы передаваться в эфир. По умолчанию в данном файле SIB5 не передаётся (не указан в `si_mapping_info`).

4. **Для MBMS** необходимо использовать файл `sib.conf.mbsfn`, который дополнительно содержит SIB13.
