## Раздел [rat.eutra] — EUTRA RAT

В разделе выполняется конфигурирование LTE-радиотехнологии (RAT) на стороне UE — выбор EARFCN, принудительные частоты и количество несущих для агрегации (CA).

| Параметр | Описание | Тип / Диапазон | Значение по умолчанию |
|----------|----------|----------------|-----------------------|
| `dl_earfcn` | Номер EARFCN нисходящего канала (DL). Определяет рабочую частоту. | `0` – `65535` | `3350` |
| `dl_freq` | Принудительное значение частоты DL (Гц), переопределяющее `dl_earfcn`. | Любое положительное число (Гц) | — |
| `ul_freq` | Принудительное значение частоты UL (Гц), переопределяющее `dl_earfcn`. | Любое положительное число (Гц) | — |
| `nof_carriers` | Количество несущих (агрегация несущих CA). | `1` – `5` | `1` |

### Расчёт частот по EARFCN

Частота рассчитывается по номеру EARFCN согласно 3GPP TS 36.101:

$$F = F_{low} + 0.1 \times (N - N_{offset})$$

Где:
- $F$ — частота (МГц)
- $F_{low}$ — нижняя граница диапазона
- $N$ — номер EARFCN
- $N_{offset}$ — смещение диапазона

**Пример для Band 1 (IMT-2100):**
- $N_{DL} = 3350$ — соответствует Band 1
- $N_{DL}$ в диапазоне 0–599 (для Band 1), но 3350 не входит в Band 1
- Проверяем Band 7 (IMT-E-2600): $N_{DL}$ 2750–3449
- **DL:** $F_{DL} = 2620 + 0.1 \times (3350 - 2750) = 2620 + 60 = 2680$ МГц
- **UL:** $F_{UL} = 2500 + 0.1 \times (3350 - 2750) = 2500 + 60 = 2560$ МГц

## Раздел [usim] — USIM

В разделе выполняется конфигурирование модуля USIM — идентификация абонента (IMSI, IMEI), ключи аутентификации (MILENAGE/XOR) и параметры для работы с физической SIM-картой.

| Параметр | Описание | Тип / Диапазон | Значение по умолчанию |
|----------|----------|----------------|-----------------------|
| `mode` | Режим USIM. | `soft` (программный), `pcsc` (физическая SIM-карта) | `soft` |
| `algo` | Алгоритм аутентификации. | `xor`, `milenage` | `milenage` |
| `op` | 128-битное поле конфигурации алгоритма оператора (OP) — шестнадцатеричная строка. | 32 hex-символа | — |
| `opc` | 128-битное зашифрованное поле конфигурации алгоритма оператора (OPc) — шестнадцатеричная строка. | 32 hex-символа | — |
| `k` | 128-битный ключ абонента — шестнадцатеричная строка. | 32 hex-символа | — |
| `imsi` | 15-значный международный идентификатор абонента (IMSI). | 15 цифр | — |
| `imei` | 15-значный международный идентификатор оборудования (IMEI). | 15 цифр | — |
| `pin` | PIN-код при использовании физической SIM-карты. | 4-8 цифр | — |
| `reader` | Имя считывателя SIM-карт (как выводится `pcsc_scan`). Пустая строка — перебор всех доступных. | Строка | — |

> **О OP и OPc:** Должен быть указан либо `op`, либо `opc` (но не оба одновременно). OPc — это зашифрованная версия OP с использованием ключа K. Алгоритм `opc` используется только при `algo = milenage`.

### [channel.dl.delay] — Задержка

Формула изменения задержки:

$$delay(t) = delay_{min} + (delay_{max} - delay_{min}) \times \frac{1 + \sin(2\pi \cdot t / period)}{2}$$

Максимальная скорость (м/с):

$$v_{max} = \frac{(delay_{max} - delay_{min}) \cdot \pi \cdot 300}{period}$$

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `enable` | Включить симулятор задержки. | `true` / `false` | `false` |
| `period_s` | Период (с). | Любое положительное число | `3600` |
| `init_time_s` | Начальное время (с). | Любое число ≥ 0 | `0` |
| `maximum_us` | Максимальная задержка (мкс). | Любое положительное число | `100` |
| `minimum_us` | Минимальная задержка (мкс). | Любое положительное число | `10` |

## Примечания

1. **Формула EARFCN → частота:** $F = F_{low} + 0.1 \times (N - N_{offset})$ по 3GPP TS 36.101.
2. **USIM:** При использовании физической SIM-карты (`mode = pcsc`) необходим считыватель PC/SC и библиотека pcsc-lite.
3. **Алгоритм Milenage:** Требует наличия OP или OPc. Если указан OP, OPc вычисляется как `OPc = AES_K(OP) XOR OP`.
4. **5G SA:** Для работы в режиме 5G Standalone необходимо задать `srate` в разделе `[rf]` и `nof_carriers > 0` в `[rat.nr]`.
