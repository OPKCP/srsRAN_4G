# mbms.conf — Конфигурация MBMS-GW (MBMS Gateway)

Файл конфигурации шлюза MBMS (MBMS-GW) в проекте srsRAN 4G. Используется для организации multicast-передач мультимедийного контента через eMBMS (Evolved Multimedia Broadcast Multicast Service).

## Раздел [mbms_gw] — Параметры MBMS-GW

В разделе выполняется конфигурирование шлюза MBMS-GW — сетевого интерфейса SGi-mb для приёма мультимедийного контента, multicast-группы M1-U для передачи на eNB и TTL multicast-пакетов.

| Параметр | Описание | Тип / Диапазон | Значение по умолчанию |
|----------|----------|----------------|-----------------------|
| `name` | Имя MBMS-GW (идентификатор). | Строка | `srsmbmsgw01` |
| `sgi_mb_if_name` | Имя TUN-интерфейса SGi-mb. | Строка | `sgi_mb` |
| `sgi_mb_if_addr` | IP-адрес интерфейса SGi-mb. | IPv4-адрес | `172.16.0.254` |
| `sgi_mb_if_mask` | Маска подсети интерфейса SGi-mb. | IPv4-маска | `255.255.255.255` |
| `m1u_multi_addr` | Многоадресная группа (multicast) для eNB. | IPv4 multicast-адрес (224.0.0.0 – 239.255.255.255) | `239.255.0.1` |
| `m1u_multi_if` | IP-адрес локального интерфейса для multicast-трафика M1-U. | IPv4-адрес | `127.0.1.200` |
| `m1u_multi_ttl` | TTL (Time-To-Live) для M1-U multicast-трафика. | `0` – `255` | `1` |

### Пояснения

- **SGi-mb (SGi-mb reference point):** Интерфейс между MBMS-GW и внешней сетью, через который поступает мультимедийный контент для broadcast/multicast-передачи.
- **M1-U:** Интерфейс между MBMS-GW и eNB для передачи пользовательских данных MBMS по UDP/IP multicast.
- **m1u_multi_ttl = 1:** Пакеты не выходят за пределы одной сети (L2-сегмента). Для маршрутизации через несколько маршрутизаторов следует увеличить TTL.

> **Архитектура:** MBMS-GW получает мультимедийный контент через интерфейс SGi-mb и передаёт его eNB через M1-U multicast. На стороне eNB MBMS должен быть включён в разделе `[embms]` файла `enb.conf`.

## Раздел [log] — Логирование

В разделе выполняется конфигурирование системы логирования MBMS-GW для диагностики multicast-передач.

| Параметр | Описание | Тип / Диапазон | Значение по умолчанию |
|----------|----------|----------------|-----------------------|
| `all_level` | Уровень логирования для всех слоёв. | `debug`, `info`, `warning`, `error`, `none` | `debug` |
| `all_hex_limit` | Лимит шестнадцатеричного дампа (байт). | Целое число ≥ 0 | `32` |
| `filename` | Путь к файлу лога. Может быть `stdout` для вывода в консоль. | Строка (путь) | `/tmp/mbms.log` |

### Слои логирования

`mbms_gw`, `all`

## Примечания

1. MBMS-GW запускается как часть процесса `srsepc`.
2. Для работы MBMS необходимо:
   - Включить `[embms] enable = true` в `[enb.conf](enb.conf.md)`.
   - Использовать файл `sib.conf.mbsfn` (с SIB13) вместо стандартного `sib.conf`.
   - Настроить multicast-маршрутизацию между MBMS-GW и eNB.
3. Адрес `m1u_multi_addr` должен совпадать с `m1u_multiaddr` в разделе `[embms]` файла `enb.conf`.
