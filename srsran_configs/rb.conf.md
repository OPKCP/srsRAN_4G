## 4G (LTE) секция

### SRB1/SRB2 — Сигнальные радиоканалы

В разделе выполняется конфигурирование сигнальных радиоканалов (SRB) для LTE — параметры RLC в режиме AM для UL и DL, таймеры повторной передачи и переупорядочивания.

SRB1 и SRB2 имеют одинаковую структуру параметров (по умолчанию закомментированы, используются значения по умолчанию):

#### RLC-конфигурация (UL AM)

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `t_poll_retx` | Таймер повторной передачи Poll (мс). | Целое ≥ 0 | `45` |
| `poll_pdu` | Количество PDU для отправки Poll. | `-1` (откл.) или целое | `-1` |
| `poll_byte` | Количество байт для отправки Poll. | `-1` (откл.) или целое | `-1` |
| `max_retx_thresh` | Максимальное количество повторных передач (UL). | `1` – `32` | `4` |

#### RLC-конфигурация (DL AM)

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `t_reordering` | Таймер переупорядочивания RLC SDU (мс). | Целое ≥ 0 | `35` |
| `t_status_prohibit` | Таймер запрета отправки статусного PDU (мс). | Целое ≥ 0 | `0` |

#### enb_specific — Специфичные для eNB параметры

| Параметр | Описание | Диапазон | Значение по умолчанию |
|----------|----------|----------|-----------------------|
| `dl_max_retx_thresh` | Максимальное количество повторных передач в DL. | `1` – `256` | `32` |

### qci_config — Конфигурация QCI

В разделе выполняется конфигурирование классов качества обслуживания (QCI) для LTE — PDCP, RLC и логические каналы для каждого класса трафика. Список профилей QCI (QoS Class Identifier), определяющих параметры радиоканалов для разных классов трафика.

#### Первый профиль — QCI 7 (GBR, Interactive gaming, VoIP)

```c
{
  qci = 7;
  pdcp_config = {
    discard_timer = -1;        // Бесконечность
    pdcp_sn_size = 12;         // Размер PDCP SN (12 или 18 бит)
  }
  rlc_config = {
    ul_um = { sn_field_length = 10; };   // UM: длина поля SN — 10 бит
    dl_um = {
      sn_field_length = 10;
      t_reordering = 45;                 // Таймер переупоряд. (мс)
    };
  };
  logical_channel_config = {
    priority = 13;               // Приоритет (меньше = выше)
    prioritized_bit_rate = -1;   // Бесконечность
    bucket_size_duration = 100;  // Длительность "ведра" (мс)
    log_chan_group = 2;          // Группа логического канала
  };
  enb_specific = {
    dl_max_retx_thresh = 32;
  };
}
```

#### Второй профиль — QCI 9 (Non-GBR, Internet, IMS signalling)

```c
{
  qci = 9;
  pdcp_config = {
    discard_timer = 150;              // 150 мс
    status_report_required = true;    // Требуется отчёт о статусе
  }
  rlc_config = {
    ul_am = {
      t_poll_retx = 120;
      poll_pdu = 64;
      poll_byte = 750;
      max_retx_thresh = 16;
    };
    dl_am = {
      t_reordering = 50;
      t_status_prohibit = 50;
    };
  };
  logical_channel_config = {
    priority = 11;
    prioritized_bit_rate = -1;
    bucket_size_duration = 100;
    log_chan_group = 3;
  };
  enb_specific = {
    dl_max_retx_thresh = 32;
  };
}
```

#### PDCP-параметры

| Параметр | Описание | Диапазон | Значение QCI 7 | Значение QCI 9 |
|----------|----------|----------|----------------|----------------|
| `discard_timer` | Таймер отбрасывания PDCP SDU (мс). `-1` — бесконечность. | `-1`, `10` – `∞` мс | `-1` | `150` |
| `pdcp_sn_size` | Размер PDCP Sequence Number (бит). | `12`, `18` | `12` | — |
| `status_report_required` | Требуется отправка PDCP Status Report. | `true` / `false` | — | `true` |

#### RLC-параметры

##### UM (Unacknowledged Mode) — QCI 7

| Параметр | Описание | Диапазон | Значение |
|----------|----------|----------|----------|
| `sn_field_length` | Длина поля SN (бит). | `5` (для UM), `10` (для UM) | `10` |
| `t_reordering` | Таймер переупорядочивания (мс). | Целое ≥ 0 | `45` |

##### AM (Acknowledged Mode) — QCI 9

| Параметр | Описание | Диапазон | Значение |
|----------|----------|----------|----------|
| `t_poll_retx` | Таймер повторной передачи Poll (мс). | Целое ≥ 0 | `120` |
| `poll_pdu` | Количество PDU для отправки Poll. | `-1` (откл.) или целое | `64` |
| `poll_byte` | Количество байт для отправки Poll. | `-1` (откл.) или целое | `750` |
| `max_retx_thresh` | Максимальное количество повторных передач. | `1` – `32` | `16` |

#### Параметры логического канала

| Параметр | Описание | Диапазон | QCI 7 | QCI 9 |
|----------|----------|----------|-------|-------|
| `priority` | Приоритет логического канала. Меньшее значение = выше приоритет. | `1` – `16` | `13` | `11` |
| `prioritized_bit_rate` | Приоритизированная битовая скорость (кБ/с). `-1` — бесконечность. | `-1` или целое | `-1` | `-1` |
| `bucket_size_duration` | Длительность ведра (мс) для модели Token Bucket. | Целое ≥ 0 | `100` | `100` |
| `log_chan_group` | Группа логического канала (LCG) для BSR. | `0` – `3` | `2` | `3` |

#### enb_specific

| Параметр | Описание | Диапазон | Значение |
|----------|----------|----------|----------|
| `dl_max_retx_thresh` | Макс. число повторных передач RLC в DL. | `1` – `256` | `32` |

### SRB1_5G/SRB2_5G — Сигнальные каналы NR

В разделе выполняется конфигурирование сигнальных радиоканалов для 5G NR — RLC в режиме AM с параметрами для UL и DL.

Структура идентична для SRB1 и SRB2:

#### RLC-конфигурация (UL AM)

| Параметр | Описание | Диапазон | Значение |
|----------|----------|----------|----------|
| `sn_field_len` | Длина поля SN (бит). | `6`, `12` | `12` |
| `t_poll_retx` | Таймер повторной передачи Poll (мс). | Целое ≥ 0 | `45` |

| `poll_byte` | Количество байт для отправки Poll. | `-1` (откл.) или целое | `-1` |
| `max_retx_thres` | Максимальное количество повторных передач. | `1` – `32` | `8` |

#### RLC-конфигурация (DL AM)

| Параметр | Описание | Диапазон | Значение |
|----------|----------|----------|----------|
| `sn_field_len` | Длина поля SN (бит). | `6`, `12` | `12` |
| `t_reassembly` | Таймер сборки RLC SDU (мс). | Целое ≥ 0 | `35` |

### five_qi_config — Конфигурация 5QI

В разделе выполняется конфигурирование классов качества обслуживания 5QI для NR — PDCP NR и RLC для каждого класса трафика.

#### Профиль 5QI 7 (GBR, Interactive gaming / VoIP — NR)

```c
{
  five_qi = 7;
  pdcp_nr_config = {
    drb = {
      pdcp_sn_size_ul = 18;     // 18 бит UL
      pdcp_sn_size_dl = 18;     // 18 бит DL
      discard_timer = 50;       // 50 мс
      integrity_protection = false;
      status_report = false;
    };
    t_reordering = 50;           // Таймер переупоряд. (мс)
  };
  rlc_config = {
    um_bi_dir = {                // UM (Unacknowledged Mode) двунаправленный
      ul_um = { sn_field_len = 12; };
      dl_um = { sn_field_len = 12; t_reassembly = 50; };
    };
  };
}
```

#### Профиль 5QI 9 (Non-GBR, Internet — NR)

```c
{
  five_qi = 9;
  pdcp_nr_config = {
    drb = {
      pdcp_sn_size_ul = 18;
      pdcp_sn_size_dl = 18;
      discard_timer = 50;
      integrity_protection = false;
      status_report = false;
    };
    t_reordering = 50;
  };
  rlc_config = {
    am = {                       // AM (Acknowledged Mode)
      ul_am = {
        sn_field_len = 12;
        t_poll_retx = 50;
        poll_pdu = 4;
        poll_byte = 3000;
        max_retx_thres = 4;
      };
      dl_am = {
        sn_field_len = 12;
        t_reassembly = 50;
        t_status_prohibit = 50;
      };
    };
  };
}
```

#### PDCP NR — параметры DRB

| Параметр | Описание | Диапазон | 5QI 7 | 5QI 9 |
|----------|----------|----------|-------|-------|
| `pdcp_sn_size_ul` | Размер PDCP SN для UL (бит). | `12`, `18` | `18` | `18` |
| `pdcp_sn_size_dl` | Размер PDCP SN для DL (бит). | `12`, `18` | `18` | `18` |
| `discard_timer` | Таймер отбрасывания SDU (мс). | Целое ≥ 0 | `50` | `50` |
| `integrity_protection` | Включить защиту целостности. | `true` / `false` | `false` | `false` |
| `status_report` | Включить отправку PDCP Status Report. | `true` / `false` | `false` | `false` |
| `t_reordering` | Таймер переупорядочивания PDCP (мс). | Целое ≥ 0 | `50` | `50` |

#### RLC NR — параметры

##### UM (Unacknowledged Mode) — 5QI 7

| Параметр | Описание | Диапазон | Значение |
|----------|----------|----------|----------|
| `sn_field_len` (UL) | Длина поля SN UL (бит). | `6`, `12` | `12` |
| `sn_field_len` (DL) | Длина поля SN DL (бит). | `6`, `12` | `12` |
| `t_reassembly` | Таймер сборки RLC (мс). | Целое ≥ 0 | `50` |

##### AM (Acknowledged Mode) — 5QI 9

| Параметр | Описание | Диапазон | Значение |
|----------|----------|----------|----------|
| `sn_field_len` (UL) | Длина поля SN UL (бит). | `6`, `12` | `12` |
| `t_poll_retx` | Таймер Poll повторной передачи (мс). | Целое ≥ 0 | `50` |
| `poll_pdu` | Количество PDU для отправки Poll. | `-1` (откл.) или целое | `4` |
| `poll_byte` | Количество байт для отправки Poll. | `-1` (откл.) или целое | `3000` |
| `max_retx_thres` | Максимальное число повторных передач (UL). | `1` – `32` | `4` |
| `sn_field_len` (DL) | Длина поля SN DL (бит). | `6`, `12` | `12` |
| `t_reassembly` | Таймер сборки RLC DL (мс). | Целое ≥ 0 | `50` |
| `t_status_prohibit` | Таймер запрета статусного PDU (мс). | Целое ≥ 0 | `50` |

## Примечания

1. **QCI (QoS Class Identifier) для LTE:** Стандартные классы QCI определены в 3GPP TS 23.203. QCI 7 — GBR, QCI 9 — Non-GBR.
2. **5QI (5G QoS Identifier) для NR:** Определены в 3GPP TS 23.501. 5QI 7 — GBR, 5QI 9 — Non-GBR.
3. **PDCP SN Size:** 12 бит = 4096 SN, 18 бит = 262144 SN.
4. **RLC UM vs AM:**
   - **UM (Unacknowledged Mode):** без подтверждения, используется для real-time трафика (VoIP, видео), где задержка критична.
   - **AM (Acknowledged Mode):** с подтверждением, используется для данных, где важна надёжность (Internet, файлы).
5. **Token Bucket:** `prioritized_bit_rate` и `bucket_size_duration` реализуют модель Token Bucket для управления скоростью логического канала. Максимальный объём "ведра" = `prioritized_bit_rate × bucket_size_duration`.
6. Все времена указаны в миллисекундах. Значение `-1` означает бесконечность.
