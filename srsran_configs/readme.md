# Конфигурационные файлы srsRAN 4G

В данном каталоге находятся конфигурационные файлы для системы srsRAN 4G, используемой для развёртывания LTE-сети с открытым исходным кодом. Файлы определяют параметры всех компонентов сети: базовой станции (eNB), пакетного ядра (EPC), абонентского устройства (UE), а также радиоресурсов и системной информации.

## Состав конфигурации

Система srsRAN 4G состоит из трёх основных компонентов, каждый из которых имеет свой файл конфигурации:

### Компоненты сети

| Компонент | Назначение | Файл конфигурации |
|-----------|------------|-------------------|
| **eNB** (eNodeB) | Базовая станция LTE | [`enb.conf`](enb.conf) — [подробное описание](enb.conf.md) |
| **EPC** (Evolved Packet Core) | Пакетное ядро (MME + HSS + SPGW) | [`epc.conf`](epc.conf) — [подробное описание](epc.conf.md) |
| **UE** (User Equipment) | Абонентское устройство | [`ue.conf`](ue.conf) — [подробное описание](ue.conf.md) |
| **MBMS-GW** | Шлюз multicast/broadcast (eMBMS) | [`mbms.conf`](mbms.conf) — [подробное описание](mbms.conf.md) |

### Вспомогательные файлы конфигурации

| Файл | Назначение | Описание |
|------|------------|----------|
| [`rr.conf`](rr.conf) | Радиоресурсы (Radio Resources): MAC, PHY, ячейки, хэндовер, измерения | [Подробное описание](rr.conf.md) |
| [`rb.conf`](rb.conf) | Радиоканалы (Radio Bearers): SRB/DRB, PDCP, RLC, QoS (QCI/5QI) | [Подробное описание](rb.conf.md) |
| [`sib.conf`](sib.conf) | Системные информационные блоки SIB1–SIB5 (3GPP TS 36.331) | [Подробное описание](sib.conf.md) |
| [`user_db.csv`](user_db.csv) | База данных абонентов HSS (IMSI, ключи, QCI, IP-аллокация) | [Подробное описание](user_db.csv.md) |

### Связи между файлами

```
enb.conf
  ├── enb_files.sib_config --> sib.conf  (SIB1, SIB2, SIB3; для MBMS: sib.conf.mbsfn)
  ├── enb_files.rr_config  --> rr.conf  (MAC/PHY/измерения/хэндовер)
  └── enb_files.rb_config  --> rb.conf  (SRB/DRB/PDCP/RLC)

epc.conf
  ├── hss.db_file --> user_db.csv  (данные абонентов)
  └── [mbms_gw]   --> mbms.conf    (если используется MBMS)

ue.conf
  └── usim --> user_db.csv  (должен соответствовать данным HSS)
```

```
                    ┌─────────────────┐
                    │    UE (srsue)   │

                    │  [enb.conf]     │

                    └────────┬────────┘

                    │   (Internet)    │
                    └─────────────────┘
```

## Быстрый старт

1. Настройте `enb.conf` — укажите идентификаторы сети (MCC, MNC), IP-адреса для S1-соединения, RF-параметры и число PRB.
2. Настройте `epc.conf` — укажите те же MCC/MNC, адрес MME, APN и путь к `user_db.csv`.
3. Заполните `user_db.csv` — добавьте абонентов с их IMSI, ключами и QCI.
4. Настройте `ue.conf` — укажите `dl_earfcn`, соответствующий eNB, и данные USIM, совпадающие с `user_db.csv`.
5. При необходимости отредактируйте `rr.conf`, `rb.conf` и `sib.conf` для управления радиоресурсами и системной информацией.
