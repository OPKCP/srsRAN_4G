# Конфигурация сети LTE (srsRAN 4G) — Production

## Обзор

Данный каталог содержит production-конфигурацию для развёртывания сети LTE на базе **srsRAN 4G** (srsENB + srsEPC).
Сеть состоит из **4 базовых станций (eNB)** и **1 ядра сети (EPC)**, работающих под единым управлением.

---

## Состав каталога

```
prod/
├── enb1/          # Базовая станция #1
│   ├── enb.conf   # Основная конфигурация eNB
│   ├── rr.conf    # Радио-ресурсы (соты, хендовер, измерения)
│   ├── rb.conf    # Конфигурация SRB/DRB
│   ├── sib.conf   # Системные информационные блоки (SIB1/SIB2/SIB3)
│   ├── mbms.conf  # MBMS (eMBMS) — широковещательный мультимедиа
│   └── ue.conf    # Параметры UE по умолчанию
├── enb2/          # Базовая станция #2 (аналогично)
├── enb3/          # Базовая станция #3 (аналогично)
├── enb4/          # Базовая станция #4 (аналогично)
└── epc/           # Ядро сети LTE (EPC)
    ├── epc.conf   # MME + HSS + SPGW конфигурация
    └── user_db.csv # База абонентов (IMSI, ключи, APN)
```

## Конфигурация хендовера (Handover)

Все eNB настроены на использование события **A3** (соседняя сота становится лучше обслуживающей на offset).

### Параметры хендовера

| Параметр           | eNB #1  | eNB #2  | eNB #3  | eNB #4  |
|--------------------|---------|---------|---------|---------|
| **A3 offset**      | 6 дБ    | 3 дБ    | 3 дБ    | 6 дБ    |
| **Hysteresis**     | 0       | 0       | 0       | 0       |
| **TTT**            | 480 мс  | 480 мс  | 480 мс  | 480 мс  |
| **Trigger quant.** | RSRP    | RSRP    | RSRP    | RSRP    |
| **Max report cells** | 1     | 2       | 2       | 1       |
| **Report interval**  | 120 с | 240 с   | 240 с   | 240 с   |
| **Meas gap период**  | -      | -       | 40 мс   | 40 мс   |

> **Рекомендация:** eNB #1 и eNB #4 используют A3-offset=6, а eNB #2 и eNB #3 — offset=3.
> Для симметричного хендовера во всех направлениях рекомендуется унифицировать эти значения.

### Матрица соседства

Список соседних сот (meas_cell_list) для каждой eNB:

| Станция | Видит соседей |
|---------|---------------|
| eNB #1  | eNB #2 (1325, PCI=2), eNB #3 (1375, PCI=3), eNB #4 (1375, PCI=4) |
| eNB #2  | eNB #1 (1300, PCI=1), eNB #3 (1375, PCI=3), eNB #4 (1375, PCI=4) |
| eNB #3  | eNB #1 (1300, PCI=1), eNB #2 (1325, PCI=2), eNB #4 (1375, PCI=4) |
| eNB #4  | eNB #1 (1300, PCI=1), eNB #2 (1325, PCI=2), eNB #3 (1375, PCI=3) |

Матрица соседства полная — все станции видят друг друга, что позволяет абоненту
хэндовериться между любыми eNB при перемещении.

## Формат файла базы абонентов (user_db.csv)

Файл `user_db.csv` содержит записи абонентов в формате:
```
IMSI,Key,OPc,AMF,SQN,QCI,APN
```

- **IMSI** — международный идентификатор абонента (15 цифр)
- **Key** — 128-битный ключ аутентификации (hex, 32 символа)
- **OPc** — операторский ключ (hex, 32 символа)
- **AMF** — флаг аутентификации (hex, 4 символа, обычно 0x8000)
- **SQN** — порядковый номер (hex, 10-16 символов)
- **QCI** — Class Identifier (например, 7 для VoIP)
- **APN** — точка доступа (опционально)

## Сетевая подсистема

- Все устройства находятся в подсети **172.18.0.0/16** (Docker-сеть)
- MME слушает S1-MME на порту по умолчанию (36412)
- GTP-U туннелирование между eNB и SPGW
- SGi интерфейс: TUN `srs_spgw_sgi` с адресом 10.0.0.1 для выхода UE в сеть

## Рекомендации

1. **Унификация хендовера:** рекомендуется выставить одинаковые A3-offset и max_report_cells
   на всех eNB для симметричного поведения.
2. **Измерения на разных частотах:** eNB #3 и eNB #4 используют `meas_gap_period = 40`,
   так как они измеряют соседей на других EARFCN (1300, 1325). Для eNB #1 и eNB #2
   это не требуется, если они не сканируют другие частоты (gap period не настроен).
3. **eNB #3 и eNB #4 на одной частоте:** убедитесь, что SDR-устройства физически разнесены
   или используется частотное/временное разделение во избежание коллизий.
4. **PIN-код SIM:** для корректной аутентификации убедитесь, что PIN-код на SIM-картах
   отключён или учтён в конфигурации UE.
