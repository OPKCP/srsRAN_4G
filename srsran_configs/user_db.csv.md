# user_db.csv — База данных пользователей HSS

CSV-файл базы данных абонентов (UE) для HSS (Home Subscriber Server) в проекте srsRAN 4G. Хранит информацию об абонентах, необходимую для аутентификации и авторизации в сети.

## Формат файла

Каждая строка, не начинающаяся с `#`, содержит запись об одном абоненте в следующем формате:

```
Name,Auth,IMSI,Key,OP_Type,OP/OPc,AMF,SQN,QCI,IP_alloc
```

## Описание полей

В данном разделе приведено описание каждого поля CSV-файла базы данных HSS. Каждая запись содержит данные для аутентификации (IMSI, ключи, алгоритм), идентификации (имя), управления сессиями (QCI) и выделения IP-адресов.

| Поле | Описание | Тип / Диапазон | Пример |
|------|----------|----------------|--------|
| **Name** | Человекочитаемое имя абонента. Игнорируется HSS, используется только для идентификации. | Строка | `ue2` |
| **Auth** | Алгоритм аутентификации, используемый UE. | `mil` (MILENAGE), `xor` (XOR) | `mil` |
| **IMSI** | Международный идентификатор абонента (International Mobile Subscriber Identity) — 15 цифр. | 15 цифр | `250010000000001` |
| **Key** | 128-битный ключ абонента K (hex), от которого производятся остальные ключи. | 32 шестнадцатеричных символа (128 бит) | `00112233445566778899aabbccddeeff` |
| **OP_Type** | Тип кода оператора. | `op` (Operator Code) или `opc` (Ciphered Operator Code) | `opc` |
| **OP/OPc** | Код оператора или зашифрованный код оператора (hex 128 бит). | 32 шестнадцатеричных символа (128 бит) | `63bfa50ee6523365ff14c1f45f88737d` |
| **AMF** | Поле управления аутентификацией (Authentication Management Field) — hex. | 2 байта, hex | `9000` |
| **SQN** | Последовательный номер UE для свежести аутентификации — hex (48 бит). | 12 шестнадцатеричных символов (48 бит) | `000000001914` |
| **QCI** | QoS Class Identifier для дефолтного bearer. | `1` – `9` | `9` |
| **IP_alloc** | Стратегия выделения IP-адреса для SPGW. | `dynamic` (автоназначение) или статический IPv4 (например `172.16.0.2`) | `dynamic` |

## Пример записи

```
ue2,mil,250010000000001,00112233445566778899aabbccddeeff,opc,63bfa50ee6523365ff14c1f45f88737d,9000,000000001914,9,dynamic
```

### Расшифровка примера

| Поле | Значение | Пояснение |
|------|----------|-----------|
| Name | `ue2` | Имя абонента |
| Auth | `mil` | Аутентификация по алгоритму MILENAGE |
| IMSI | `250010000000001` | IMSI: MCC=250 (Россия), MNC=01, остальные цифры — идентификатор |
| Key | `00112233445566778899aabbccddeeff` | Ключ K (128 бит) |
| OP_Type | `opc` | Используется зашифрованный код оператора (OPc) |
| OP/OPc | `63bfa50ee6523365ff14c1f45f88737d` | OPc (128 бит) |
| AMF | `9000` | Поле управления аутентификацией |
| SQN | `000000001914` | Последовательный номер (десятичное 0x1914 = 6420) |
| QCI | `9` | Non-GBR (Internet) |
| IP_alloc | `dynamic` | IP-адрес назначается автоматически |

## Структура IMSI

IMSI состоит из:

- **MCC** (3 цифры) — Mobile Country Code
- **MNC** (2-3 цифры) — Mobile Network Code
- **MSIN** (остальные цифры) — Mobile Subscriber Identification Number

**Пример:** IMSI = `250010000000001`
- MCC = `250` (Россия)
- MNC = `01`
- MSIN = `0000000001` (номер абонента)

## Диапазоны значений

| Поле | Диапазон |
|------|----------|
| IMSI | 15 десятичных цифр |
| Key | 32 hex-символа (128 бит), любой hex |
| OP/OPc | 32 hex-символа (128 бит), любой hex |
| AMF | 4 hex-символа (16 бит) |
| SQN | 12 hex-символов (48 бит) |
| QCI | от 1 до 9 (стандартные классы 3GPP) |
| IP_alloc | `dynamic` или корректный IPv4-адрес |

## Примечания

1. **MILENAGE vs XOR:**
   - **MILENAGE** — стандартный алгоритм аутентификации 3GPP (рекомендуется).
   - **XOR** — упрощённый алгоритм для тестирования (небезопасен, только для отладки).
2. **OP vs OPc:** Если используется `mil` (MILENAGE), должен быть указан либо OP, либо OPc. Разница: OPc = AES-128 с ключом K, применённый к OP.
3. **QCI (QoS Class Identifier):**
   - QCI 5 — IMS signalling
   - QCI 7 — GBR (Interactive gaming, VoIP)
   - QCI 8 — Non-GBR (Internet)
   - QCI 9 — Non-GBR (Internet, по умолчанию)
4. **Строки, начинающиеся с `#`:** Игнорируются и будут перезаписаны при записи файла. Не используйте `#` для комментариев в активных строках.
5. **IP_alloc = dynamic:** SPGW автоматически выделяет IP-адрес из пула (настраивается отдельно).
6. **HSS** загружает этот файл при запуске EPC. После изменения файла требуется перезапуск `srsepc`.
