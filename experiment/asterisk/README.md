# Asterisk — голосовые вызовы в LTE-пикосоте (srsRAN)

Обеспечивает **SIP/VoIP-голосовые вызовы** между абонентами LTE-сети (srsRAN).
В LTE голос идёт как VoIP-пакеты поверх PDN-сессии (не выделенный канал).
Asterisk играет роль внутреннего SIP-сервера.

## Архитектура

```
Телефон A (10.0.0.14) ──(SIP/RTP)──► Asterisk (10.0.0.1) ──(SIP/RTP)──► Телефон B (10.0.0.15)
        ▲                                                                    ▲
        └──────────────────────── LTE-eNB/EPC (10.0.0.0/24) ────────────────┘
```

- **Asterisk** разворачивается в **network namespace контейнера EPC** (pi5-2),
  чтобы оказаться в подсети абонентов `10.0.0.0/24` (интерфейс srs_spgw_sgi = 10.0.0.1).
- Телефоны (шлюз `10.0.0.1`) видят Asterisk на **`10.0.0.1:5060`** (SIP).

## Хост

- **pi5-2** (вторая малинка, `192.168.1.16`) — там же, где EPC (srsepc-контейнер `epc`).
- Образ: `andrius/asterisk:latest` (Asterisk 22.10.1, arm64) через Docker.

## Абоненты (масштабируемо)

| SIP-номер | IMSI (абонент ядра) | PIN/креды |
|-----------|---------------------|-----------|
| 1001 | 250630000000001 (ue1) | 1001 / 1001secret |
| 1002 | 250630000000002 (ue2) | 1002 / 1002secret |
| 1003 | 250630000000003 (ue3) | 1003 / 1003secret |
| 1004 | 250630000000004 (ue4) | 1004 / 1004secret |

**Расширение:** добавить секцию `[100X]` + `[100X-aor]` + `[100X-auth]` в
`pjsip.conf` (по шаблону). Dialplan `_100X` в `extensions.conf` уже обрабатывает
все 1001..1009 — новый абонент становится дозвоняемым без правки dialplan.
SIM-карту программировать под соответствующий IMSI из `user_db.csv` EPC.

## Файлы

- `pjsip.conf` — конфигурация PJSIP (endpoints/aor/auth для абонентов, transport UDP 5060)
- `extensions.conf` — dialplan (`lte-local` context, паттерн `_100X`)
- `run_asterisk_pi5-2.sh` — скрипт запуска контейнера (детерминированный)

## Запуск (pi5-2)

```bash
# файлы должны лежать в ~/srsran/asterisk/ (или любой каталог, CONF=$DIR)
bash ~/srsran/asterisk/run_asterisk_pi5-2.sh
```

Скрипт делает `docker rm -f asterisk` и запускает новый контейнер в
`--network container:epc`. **Важно:** контейнер `epc` (srsepc) должен быть запущен.

## Настройка телефона

На телефоне (SIP-софтфон, например Zoiper/Linphone):
- **Домен/сервер**: `10.0.0.1` (или через LTE IP-шлюз)
- **Порт**: 5060
- **Имя пользователя**: номер (1001 и т.п.)
- **Пароль**: из pjsip.conf (1001secret и т.п.)
- Убедиться, что в телефоне включены мобильные данные (для доступа в 10.0.0.0/24).

## Проверка

```bash
docker exec asterisk asterisk -rx 'pjsip show endpoints'   # регистрация абонентов
docker exec asterisk asterisk -rx 'dialplan show lte-local'
```

## VM/доки доступ

Asterisk слушает SIP на `0.0.0.0:5060` (UDP) в namespace epc → доступен телефонам
на `10.0.0.1:5060`. RTP-порт по умолчанию (не ограничен в pjsip.conf; для продакшена
стоит задать `rtp.conf` с диапазоном 10000-10100).
