# SA6 — Arinst 6G Spectrum Analyzer: программное управление

Модуль для программного управления анализатором спектра / генератором
**Arinst SA6** («6G Spectrum Analyzer») через виртуальный COM-порт по
официальному **Arinst protocol** (ASCII, 115200 бод, CR/LF).

## Возможности

- снятие спектра (массив «частота → уровень дБм») — `scan()`;
- изменение параметров захвата: начальная/конечная частота, шаг, внутренний аттенюатор;
- управление встроенным генератором: вкл/выкл, частота, выходная мощность;
- обнаружение пиков излучения с антенны — `find_peaks()` / `peak_indices()`;
- автоопределение COM-порта по VID/PID устройства.

## Установка

```bash
pip install -r sa6/requirements.txt   # pyserial, numpy
```

## Быстрое использование (CLI)

```bash
# Снять спектр 35–1000 МГц, шаг 1 МГц, и вывести пики излучения
python sa6/sa6.py --start 35 --stop 1000 --step 1 --peaks

# То же, но в узкой полосе около интересующего диапазона + аттенюатор 10 дБ
python sa6/sa6.py --start 869 --stop 895 --step 0.1 --att 10 --peaks

# Включить генератор на 1100 МГц мощностью −20 дБм, затем сделать скан с tracking
python sa6/sa6.py --gon --freq 1100 --power -20 --start 1050 --stop 1150 --step 0.5
```

### Профили лабораторного стенда srsRAN (Band 3 / FDD 1800 МГц)

Стенд srsRAN_4G работает в диапазоне E-UTRA Band 3:
**DL** (eNB → UE) ~1815 МГц, **UL** (UE → eNB) ~1720 МГц.
В модуль встроены готовые профили `dl` и `ul`, которые заменяют
`--start/--stop/--step/--att` на частоты стенда.

```bash
# Проверка, что eNB реально излучает в DL (~1815 МГц)
python sa6/sa6.py --profile dl --peaks

# Мониторинг UL: UE передаёт импульсно, поэтому ловим max-hold за 200 сканов.
# Отдельный скан может не попасть в передачу UE.
python sa6/sa6.py --profile ul --monitor 200 --peaks
```

> **Почему мониторинг для UL:** в FDD UE передаёт только в выделенных
> физических ресурсах по расписанию (импульсно), а не непрерывно, как eNB в DL.
> `--monitor N` делает N сканов и накапливает максимум уровня на каждой частоте
> (max-hold), что позволяет увидеть короткие UL-всплески.


## Использование как библиотеки

```python
from sa6 import SA6

# Порт можно указать вручную («COM3») или оставить None для автоопределения
sa6 = SA6(port=None)

# 1) Снять спектр
res = sa6.scan(start_hz=869_000_000, stop_hz=895_000_000,
               step_hz=100_000, attenuation_db=0)
for f, a in zip(res.frequencies, res.amplitudes):
    print(f"{f/1e6:.3f} MHz  {a:.2f} dBm")

# 2) Найти пики излучения
peaks = sa6.find_peaks(869_000_000, 895_000_000, 100_000)
for f, a in peaks:
    print(f"ПИК {f/1e6:.3f} MHz  {a:.2f} dBm")

# 3) Генератор
sa6.generator_on()
sa6.generator_set_frequency(1_100_000_000)
sa6.generator_set_output(-20)      # -15..-25 дБм
sa6.generator_off()

# 4) Мониторинг с max-hold (для импульсного UL UE)
hold = sa6.monitor(start_hz=1_713_000_000, stop_hz=1_733_000_000,
                   step_hz=100_000, sweeps=200)
peaks = hold.find_peaks(threshold_db=-80, min_distance_hz=2_000_000)
for i in peaks:
    print(f"UL-пик {hold.frequencies[i]/1e6:.3f} MHz  {hold.amplitudes[i]:.2f} dBm")

sa6.close()
```

## Протокол (кратко)

Формат пакета: `"<command> <arg1> <arg2> … <index>\r\n"`.

| Команда | Назначение |
|---------|------------|
| `gon <idx>` | включить генератор |
| `gof <idx>` | выключить генератор |
| `scf <freq_Hz> <idx>` | частота генератора |
| `sga <fmt_amp> <idx>` | мощность генератора |
| `scn20 …` | скан без tracking (8 аргументов) |
| `scn22 …` | скан с tracking |

Каждая точка амплитуды — 2 байта: 5 старших бит — индекс (проверка целостности),
11 младших — закодированная амплитуда:
```
amplitude = (80.0*10.0 - data) / 10.0 + attenuation  [дБм]
```

Официальный документ протокола: `arinst.ru/files/Protocol.zip`.

## Известное ограничение

Устройство определяется как STM Virtual COM Port (`VID 0483 / PID 5740`).
Если в **Диспетчере устройств** порт показывает ошибку (код 10) или второй
интерфейс «ADC FS» (код 28) — надо установить драйвер виртуального COM-порта
VCP от STMicroelectronics (есть в официальном архиве производителя) и
перезапустить устройство. Без рабочего COM-порта модуль не сможет общаться.
